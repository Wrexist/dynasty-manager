## Methodology notes

- Sim runs the real game loop: `advanceWeek()` → `playCurrentMatch()` × 46 weeks → `endSeason()`.
- Player club is `manchester-city` (eng-1). Their matches use auto-filled lineups (no tactical input).
- Only the player's country pyramid (eng, eng-2, eng-3, eng-4) is simulated — `initGame` scopes `divisionClubs` to `countryLeagues`. Other country leagues (spa/ita/ger/fra/…) live in the data but aren't played out week-to-week, so they aren't in the tables below.
- Goals-per-match pulls from `state.divisionFixtures[leagueId]` filtered to `played=true`.
- Transfer counts use `state.transferNews` deltas between seasons.
- Market snapshots taken every week (46 per season), so "avg simultaneous" is smoothed across the whole season.
- Random seed is not fixed — re-runs will vary. Numbers should be stable to ±10% across runs; anything else is worth investigating.
