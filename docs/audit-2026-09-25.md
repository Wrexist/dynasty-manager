eligible new Apple ID (RevenueCat SDK 12 checks eligibility through StoreKit 2). Before 21 Sep the
Yearly plan never reached the screen (wrong ID), so that offer could not be used by anyone.

**Remaining explanations (need RevenueCat data or a device check):**
- ✔ The trial is offered **once per device, before any gameplay** (`TitleScreen.tsx` → `/subscribe`),
  then never again: `ProUpsell` and Shop have no trial path.

- Downloads are ~14/day (owner's 24 Sep conversion doc: 191 in 14 days), so the trial window only
  sees ~100 installs. A handful of trials a week is the realistic ceiling at that volume.
- No analytics transport by design → paywall views/dismissals are unmeasurable; RevenueCat charts
  are the only funnel data.

**Check these, in order (5 minutes):**

  `text-micro` token already exists. Add a ceiling check like `i18n:check`.

  files ignore it. Add a root `reduce-motion` class.
