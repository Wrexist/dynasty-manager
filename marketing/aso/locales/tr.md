## Keyword rationale
- "teknik direktor" stays first: it's the dominant Turkish football-management head term (the DT role) and is almost UNCONTESTED by the foreign giants — Top Eleven/Soccer Manager fight over "menajer", so claiming the head-coach term is a low-competition win. Kept unaccented ("direktor") because Turkish iOS users routinely type without diacritics.
- NEW: added "menajerlik" — the category phrase "menajerlik simülasyonu" is exactly what the strongest local text-sim (Football-Agent / "Futbolcu Menajeri") leads on. Paired with the existing "simulasyon" token, the field now matches that two-word query without spending a full phrase; it's a distinct surface form from the Subtitle's "Menajeri", so it indexes rather than duplicating.
- NEW: added "kupa" (cup) to ride the World Cup window plus domestic/continental-cup intent — a distinct competition term with no Name/Subtitle collision.
- "menajer" is still deliberately excluded: the Subtitle carries "Menajeri" and the Name carries "Futbol", so "futbol menajeri" is already indexed — repeating it would burn characters.
- Dropped "antrenor" (a lower-intent synonym of the already-present "teknik direktor") and "dizilis" to make room; "kadro/transfer/taktik" already mirror the squad/tactics tab language Turkish players expect.
- "yerli" (domestic/local) was considered and REJECTED — it's a trust signal that only fits actually-Turkish-made games (İmparator, LFM lean on it). We are not a yerli title, so claiming it would be inaccurate.
- "milli takim" (national team) + "penalti" carry the WC hook without duplicating any Name/Subtitle word.
- Description change: the anti-grind + no-subscription wedge (the one thing Top Eleven's hidden energy/rest-pack grind and FM26 Mobile's Netflix paywall structurally can't say) is now moved into line 2, so it lands in the pre-"more" preview instead of being buried mid-body.
